Glmnet

Now let’s use glmnet to apply regularization!

The glmnet package fits regularized regression models (like Lasso, Ridge, and Elastic Net).

Fits a set of models for a sequence of λ values that you specify (our grid)

alpha=1 is the lasso penalty, and alpha=0 the ridge penalty.

Cross-Validation

Now lets use cross validation to select the best lambda

cv.glmnet() Performs k-fold cross-validation (default: 10-fold) to automatically find the optimal λ.

It internally calls glmnet() multiple times for different λ’s and partitions of the data.

lambda.min → λ giving the minimum cross-validation error.

Lasso Regression

#lasso regression (alpha=1, search for best lambda) and do CV
modelL<-cv.glmnet(x=as.matrix(X), y=Y[,1], lambda=grid, alpha=1)

#extract coefficients

NOTE**

In glmnet, the deviance is the model’s measure of lack of fit — like the residual sum of squares

For each value of λ (the regularization parameter), the model has a certain deviance. The dev.ratio is the fraction of deviance explained by the model relative to the null model (a model with only the intercept).
