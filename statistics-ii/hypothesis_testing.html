Seems that weight is not normally distributed (p-value < 0.05) but we have a medium sample (159 obs) and we are going to test means, so we can use the parametric tests.

Let’s try both approaches:

Differences between 2 groups - ttest / Wilcox

dd %>%
  filter(Species == "Pike" | Species == "Perch") %>%
   wilcox.test(Weight ~ Species, , data=.)

    Wilcoxon rank sum test with continuity correction

data:  Weight by Species
W = 239, p-value = 0.002018
alternative hypothesis: true location shift is not equal to 0
dd %>%
  filter(Species == "Pike" | Species == "Perch") %>%
  t.test(Weight ~ Species, data=.)

    Welch Two Sample t-test

If the p-value is close to 0 for the Wilcoxon/t test, this indicates a statistically significant difference between the two groups.

You would use two tests if you are not entirely sure from one test, or if you need to use a non-parametric test.

The adjusted one corrects for when groups are not independent. In this example, it doesn’t matter which one we look at, but if we suspect that the groups are not independent, we should use the adjusted one.

Dependent groups are individuals in the first time before taking the drug and and after taking the drug. Dependent groups can also be measuring different things in the same individuals. Independent groups are groups with different individuals.

Gives us a lot of combinations because we have a lot. Looks at the p-value and if it is significant, they are different.
