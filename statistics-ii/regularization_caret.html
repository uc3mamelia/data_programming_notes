Train models using Caret

We will use 10-fold cross validation to look for the best values of lambda in Lasso and Ridge, and also for alpha in ElasticNet.

  • The dataset is split into 10 subsets (or folds)
  • The model is trained on 9 folds and tested on the remaining fold.
  • This process repeats 10 times, each time using a different fold as the test set.

Lambda possible values

# This creates a sequence of 100 possible lambda values (a broad range) - those to try during training
lambda <- 10^seq(-3, 3, length = 100)

For each lambda value, the model is trained and evaluated on all 10 folds. The lambda value with the lowest average error will be chosen as the best lambda

Train Ridge regression with caret (alpha = 0)

ridge <- train(
  sales ~., # input data
  data = train.data, # specify data
  method = "glmnet", # specify method
  trControl = trainControl("cv", number = 10), # specify how you want the cross-validation to be performed, cv is cross validation, number is number of folds
  tuneGrid = expand.grid(alpha = 0, lambda = lambda) # set of lambda values to test (we provide them), R is performing parameter tuning
)

Train ElasticNet with caret

elastic <- train(
  sales ~., data = train.data, method = "glmnet",
  trControl = trainControl("cv", number = 10),
  tuneLength = 10 #number of combinations to test (we do not provide values, caret chooses)
  )

Here, alpha will vary between 0 and 1, allowing Elastic Net to balance Ridge and Lasso. If we don’t provide values for alpha, R will be able to try various ones.

tuneLength = 10 tells caret to automatically generate a grid of 10 values for alpha and lambda, which will adjust the penalty mix and strength based on cross-validation.

Make predictions (test data)

To make predictions with the trained Lasso and Elastic Net models in caret, you can use the predict() function, specifying the new data you want to predict on.

The predict() function automatically uses the best-tuned parameters (best lambda and alpha for each model) stored in the finalModel within the caret object.

elastic_predictions <- predict(elastic, newdata = test.data)

ridge_predictions <- predict(ridge, newdata = test.data)

lasso_predictions <- predict(lasso, newdata = test.data)

linear_predictions <- predict(linear, newdata = test.data )

Compute MSE on test data

Comparison of each model’s error on the test data, helping you to identify which model performs best

mse <- function(actual, predicted) {
  mean((actual - predicted)^2)
}

# Calculate MSE for each model
ridge_mse <- mse(test.data$sales, ridge_predictions)
lasso_mse <- mse(test.data$sales, lasso_predictions)
elastic_mse <- mse(test.data$sales, elastic_predictions)
linear_mse <-  mse(test.data$sales, linear_predictions)
