Qualitative Analysis

Sex, martial status, education, and occupation are all categorical values. We will conduct a chi-squared test on those.

Sex and Education

Is sex proportional to education?

H0: sex and education proportions are equal.

H1: sex and education proportions are not equal.

# 1. Contingency table for sex and education
ConTtable <- table(population$Sex, population$Education)
RConTtable<-prop.table(ConTtable)*100

# 2. Graphical visualization of the table.
balloonplot(t(RConTtable), main ="Sex", xlab ="", ylab="",
            label = FALSE, show.margins = FALSE)

Visually, we can see that high school has larger dots across both males and females.

# chi square test
chisq.test(population$Sex, y = population$Education)

Multi-linear Regression

While this dataset only has 2 quantitative variables, I want to show that I can conduct a multi-linear regression, so solely for the purpose of demonstration I am going to create two fake variables: number of children and weight. Obviously, in a real-world dataset doing this would be entirely problematic, so I cannot emphasis more that this is just for demonstration.

# sorts data by income
population <- population[order(population$Income), ]

# find halfway point of data
n <- nrow(population)
half <- n / 2

# Assign 0–3 to the bottom 50% (lower income group)
population$number_of_children <- NA
population$number_of_children[1:half] <- sample(0:3, size = half, replace = TRUE)

# Assign 3–5 to the top 50% (higher income group)
population$number_of_children[(half + 1):n] <- sample(3:5, size = half, replace = TRUE)

# creates weight randomly generated
population$weight <- sample(47:77, size = 2000, replace = TRUE)

I used some descriptive statistical tools in this assignment: I looked at mean, max, min, and boxplots. Mean is the average of a dataset - all points are added together and then divided by the total number of observations. Max is the highest number in a set of observations. Min is the lowest number in a set of observations. A boxplot visualizes the median, spread, and outliers of a numerical variable.

For qualitative analysis, I used hypothesis testing, balloon plots, chi squared testing and cramers V. Hypothesis testing is a tool to make inferences about a population by examining a sample of its data. The null hypothesis always assumes the default, whereas the alternative hypothesis tests the idea you want to validate. The balloon plot is a visualization tool that uses circles in a grid. The size of the balloon is proportional to the value it represents, and can compare sizes across different categories. Chi Square test makes claims about proportions in categorical data. It is a type of test that can be used with hypothesis testing to determine inference. The Cramer’s V test, used in conjunction with the Chi Square test, measures the association of the two variables between 0-1, with 1 representing a perfect association.

For the first quantitative analysis, I used a simple linear regression. A simple linear regression studies the correlation between one independent variable (X) and it dependent variable (Y). It finds a linear relationship between the two variables and fits a ‘best-fit’ straight line across the data. The space between the actual value and the predicted value is called a ‘residual’. A simple linear regression assumes a linear relationship, homogeneity (that the errors have a mean of zero), homoscedasticity (that the variance of the errors is constant), independence of the errors (one observation doesn’t imply anything about the other), and normality (that the errors follow a normal distribution). To check these assumptions, I conducted residual analysis. I also used the simple linear model to predict observations (later combined with confidence intervals to give a range of the predicted observation) and compared predicted and actual values to evaluate the model.

For the second analysis, I used a multi-linear regression looking at the relationship of indepdent variables age, number of children, and weight on dependent variable income. A multi-linear regression is different from a simple linear regression because it looks at more than one independent variable. After building and evaluation the model, I compared the first linear model with the second multi-linear model using an ANOVA test, which evaluates variance between two groups.
